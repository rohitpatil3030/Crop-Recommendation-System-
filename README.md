# Crop-Recommendation-System
🌱 Crop Recommendation System
This project uses Machine Learning to recommend the most suitable crop to grow based on soil parameters like pH, temperature, humidity, and nutrient levels (N, P, K). It also includes a worm detection module using image classification to identify crop infections.

🔧 Features
Predicts the best crop for given soil data using ML models (SVM, Decision Tree, Random Forest).
Detects worms in crop images using CNN (Convolutional Neural Networks).
Simple user interface for input and results.
Helps promote precision farming and sustainable agriculture.

🛠️ Technologies Used
Python, Pandas, NumPy, Scikit-learn
TensorFlow/Keras for CNN
OpenCV for image processing
Streamlit or Flask (for frontend if used)

🚀 How to Run
Clone the repo:
git clone https://github.com/yourusername/crop-recommendation-system.git

Install dependencies:
pip install -r requirements.txt

Run the app:
python app.py or streamlit run app.py
